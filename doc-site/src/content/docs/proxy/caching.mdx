The Proxy Engine includes a complete HTTP caching implementation that reduces origin server load by 70-90% and improves response times from 100ms+ to &lt;5ms for cached content.

## Overview

The cache system implements RFC 7234 (HTTP Caching) with support for:

- Cache-Control directives (max-age, s-maxage, no-store, private)
- ETag and Last-Modified validation
- Conditional requests (If-None-Match, If-Modified-Since)
- LRU eviction when memory limits reached
- Optional AES-GCM encryption for cached data
- Background cleanup of expired entries
- Per-route cache configuration

## Basic Usage

```typescript
import { HTTPCacheManager } from "@browserx/proxy-engine";

const cache = new HTTPCacheManager({
  maxMemoryMB: 100,        // 100MB cache size
  defaultTTL: 300,         // 5 minutes default
  enableDiskCache: false,  // Memory only
});

// Check if response is cacheable
if (cache.isCacheable(request, response)) {
  // Generate cache key
  const cacheKey = cache.generateCacheKey(
    request.method,
    request.url,
    varyHeaders
  );

  // Store in cache
  await cache.store(cacheKey, response);
}

// Retrieve from cache
const cached = await cache.get(cacheKey);
if (cached) {
  // Serve from cache - 70-90% faster than origin
  return cached.response;
}
```

## Cache Control

### Cacheable Responses

The cache only stores responses that meet all criteria:

1. **Method**: GET or HEAD
2. **Status**: 200, 203, 206, 300, 301, 404, 410
3. **Cache-Control**: Not `no-store`, not `private`
4. **Headers**: Has `max-age`, `s-maxage`, or `Expires`

```typescript
// Cacheable
HTTP/1.1 200 OK
Cache-Control: public, max-age=3600
Content-Type: application/json

// Not cacheable - no-store
HTTP/1.1 200 OK
Cache-Control: no-store

// Not cacheable - private (shared cache)
HTTP/1.1 200 OK
Cache-Control: private, max-age=3600

// Not cacheable - no caching directive
HTTP/1.1 200 OK
Content-Type: application/json
```

### Cache-Control Directives

#### max-age

Specifies how long the response is fresh (in seconds):

```text
Cache-Control: max-age=3600

Cached at: t=0
Fresh until: t=3600s (1 hour)
Stale after: t=3600s
```

#### s-maxage

Shared cache specific max-age (overrides max-age for proxies):

```text
Cache-Control: max-age=600, s-maxage=3600

Browser cache: 600s (10 minutes)
Proxy cache: 3600s (1 hour)
```

#### no-store

Never cache the response:

```text
Cache-Control: no-store

→ Response not stored in cache
```

#### no-cache

Cache but revalidate before serving:

```text
Cache-Control: no-cache

→ Stored but always revalidated with origin
```

#### private

Only cacheable by browser, not shared caches:

```text
Cache-Control: private, max-age=3600

→ Not cached by proxy (shared cache)
→ Cached by browser (private cache)
```

#### public

Explicitly cacheable by any cache:

```text
Cache-Control: public, max-age=3600

→ Cached by proxy and browser
```

## Cache Keys

Cache keys uniquely identify cached responses. Keys are generated from:

1. HTTP method
2. URL
3. Vary headers

```typescript
// Simple cache key (no Vary)
const key1 = cache.generateCacheKey("GET", "https://api.example.com/users", {});
// → "GET:https://api.example.com/users"

// Cache key with Vary headers
const key2 = cache.generateCacheKey(
  "GET",
  "https://api.example.com/users",
  { "accept-encoding": "gzip", "accept-language": "en" }
);
// → "GET:https://api.example.com/users:accept-encoding=gzip:accept-language=en"
```

### Vary Header

The `Vary` response header indicates which request headers affect the response:

```text
HTTP/1.1 200 OK
Vary: Accept-Encoding, Accept-Language
Content-Type: application/json

→ Cache separate responses for different Accept-Encoding and Accept-Language values
```

**Example**:

```typescript
// Request 1: Accept-Encoding: gzip
// → Cached with key: GET:/api/users:accept-encoding=gzip

// Request 2: Accept-Encoding: br
// → Different cache key: GET:/api/users:accept-encoding=br
// → Separate cache entry

// Request 3: Accept-Encoding: gzip
// → Same cache key as Request 1
// → Cache hit!
```

## Conditional Requests

### ETag Validation

ETag (Entity Tag) identifies a specific version of a resource:

```text
Initial Request:
GET /api/users HTTP/1.1

Response:
HTTP/1.1 200 OK
ETag: "abc123"
Cache-Control: max-age=60

→ Cached with ETag

After expiration (t > 60s):
GET /api/users HTTP/1.1
If-None-Match: "abc123"

If not modified:
HTTP/1.1 304 Not Modified
ETag: "abc123"

→ Cache entry refreshed (timestamp updated)

If modified:
HTTP/1.1 200 OK
ETag: "xyz789"

→ Cache entry replaced with new response
```

**Implementation**:

```typescript
const cached = await cache.get(cacheKey);

if (cached && cache.needsRevalidation(cached)) {
  // Add conditional headers
  const revalidationHeaders = cache.getRevalidationHeaders(cached);
  // → { "if-none-match": "abc123" }

  const response = await fetch(url, {
    headers: { ...requestHeaders, ...revalidationHeaders },
  });

  if (response.status === 304) {
    // Not modified - refresh cache timestamp
    await cache.handleNotModified(cacheKey);
    return cached.response;
  } else {
    // Modified - store new response
    await cache.store(cacheKey, response);
    return response;
  }
}
```

### Last-Modified Validation

Last-Modified header indicates when the resource was last changed:

```text
Initial Request:
GET /api/users HTTP/1.1

Response:
HTTP/1.1 200 OK
Last-Modified: Wed, 15 Jan 2025 10:00:00 GMT
Cache-Control: max-age=60

After expiration:
GET /api/users HTTP/1.1
If-Modified-Since: Wed, 15 Jan 2025 10:00:00 GMT

If not modified:
HTTP/1.1 304 Not Modified

If modified:
HTTP/1.1 200 OK
Last-Modified: Wed, 15 Jan 2025 11:00:00 GMT
```

## Eviction Strategies

### LRU (Least Recently Used)

Current implementation uses LRU eviction:

```typescript
// Cache at 99MB, maxMemoryMB = 100MB
// New entry: 5MB

→ Evict oldest entries until space available
→ Evicted: entry1 (2MB), entry2 (3MB)
→ Store new entry (5MB)
→ Cache now: 99MB
```

**Behavior**:

1. Entries stored in insertion order (JavaScript Map)
2. When memory limit reached, remove first entry (oldest)
3. Continue removing until enough space
4. Store new entry

### Future: LFU and FIFO

Planned eviction strategies:

- **LFU** (Least Frequently Used): Evict entries with lowest access count
- **FIFO** (First In First Out): Evict oldest entries by timestamp

## Cache Operations

### Store Response

```typescript
const response = {
  status: 200,
  headers: {
    "content-type": "application/json",
    "cache-control": "public, max-age=3600",
    "etag": '"abc123"',
  },
  body: new TextEncoder().encode(JSON.stringify(data)),
};

if (cache.isCacheable({ method: "GET" }, response)) {
  const cacheKey = cache.generateCacheKey("GET", url, varyHeaders);
  await cache.store(cacheKey, response);
}

// Logged:
// [CACHE STORE] GET:https://api.example.com/users (size: 12.34 KB, TTL: 3600s)
```

### Retrieve Response

```typescript
const cacheKey = cache.generateCacheKey("GET", url, varyHeaders);
const cached = await cache.get(cacheKey);

if (cached) {
  console.log("Cache hit!");
  // Age header automatically added
  console.log(cached.response.headers["age"]); // "45" (seconds since cached)
  return cached.response;
} else {
  console.log("Cache miss - fetch from origin");
}

// Logged:
// [CACHE HIT] GET:https://api.example.com/users (age: 45.2s/3600s)
```

### Invalidate Cache

```typescript
// Invalidate specific entry
cache.invalidate("GET:https://api.example.com/users");

// Invalidate by pattern
cache.invalidatePattern(/\/api\/users\/*/);

// Clear all cache
cache.clear();
```

### Purge Cache

```typescript
// Purge all entries
const count = cache.purge();
console.log(`Purged ${count} entries`);

// Purge matching pattern
const count = cache.purge("/api/users/*");
console.log(`Purged ${count} entries`);
```

## Integration with Gateway

### Automatic Caching Middleware

```typescript
import { GatewayServer, HTTPCacheManager } from "@browserx/proxy-engine";

const cache = new HTTPCacheManager({
  maxMemoryMB: 500,
  defaultTTL: 300,
});

const server = new GatewayServer({
  host: "0.0.0.0",
  port: 8080,
  routes: [/* routes */],
  cache,  // Enable caching
});

// Requests automatically cached based on Cache-Control headers
```

### Custom Caching Middleware

```typescript
class CacheMiddleware implements RequestMiddleware {
  readonly name = "cache";

  constructor(private cache: HTTPCacheManager) {}

  async processRequest(
    request: HTTPRequest,
    context: RequestContext
  ): Promise<MiddlewareResult> {
    // Generate cache key
    const varyHeaders = this.extractVaryHeaders(request);
    const cacheKey = this.cache.generateCacheKey(
      request.method,
      request.uri,
      varyHeaders
    );

    // Check cache
    const cached = await this.cache.get(cacheKey);

    if (cached) {
      // Check if revalidation needed
      if (this.cache.needsRevalidation(cached)) {
        // Add conditional headers
        const revalidationHeaders = this.cache.getRevalidationHeaders(cached);
        for (const [key, value] of Object.entries(revalidationHeaders)) {
          request.headers[key] = value;
        }

        // Store cache key for response handling
        context.metadata.cacheKey = cacheKey;
        context.metadata.cachedResponse = cached;

        return { type: "continue" };
      }

      // Fresh cache hit - serve immediately
      return {
        type: "respond",
        response: cached.response,
      };
    }

    // Cache miss - store key for response handling
    context.metadata.cacheKey = cacheKey;

    return { type: "continue" };
  }
}

class CacheResponseMiddleware implements ResponseMiddleware {
  readonly name = "cache-response";

  constructor(private cache: HTTPCacheManager) {}

  async processResponse(
    request: HTTPRequest,
    response: HTTPResponse,
    context: RequestContext
  ): Promise<HTTPResponse> {
    const cacheKey = context.metadata.cacheKey as string;
    const cachedResponse = context.metadata.cachedResponse;

    // Handle 304 Not Modified
    if (response.statusCode === 304 && cachedResponse) {
      await this.cache.handleNotModified(cacheKey);
      return cachedResponse.response;
    }

    // Store cacheable responses
    if (this.cache.isCacheable(request, response)) {
      await this.cache.store(cacheKey, response);
    }

    return response;
  }
}
```

## Best Practices

1. **Set appropriate TTLs**:
   - Static assets: `max-age=31536000` (1 year)
   - API data: `max-age=300` (5 minutes)
   - Dynamic content: `max-age=60` (1 minute)
   - User-specific: `private, max-age=600`

2. **Use ETags for validation**:
   ```text
   ETag: "content-hash-abc123"
   Cache-Control: max-age=60
   ```

3. **Leverage s-maxage**:
   ```text
   Cache-Control: max-age=60, s-maxage=3600
   → Proxy caches longer than browser
   ```

4. **Vary on relevant headers**:
   ```text
   Vary: Accept-Encoding, Accept-Language
   → Separate cache for gzip/br and en/es
   ```

5. **Monitor cache performance**:
   ```typescript
   setInterval(() => {
     const stats = cache.getStats();
     const hitRate = stats.hits / (stats.hits + stats.misses) * 100;
     console.log(`Cache hit rate: ${hitRate.toFixed(2)}%`);
   }, 60000);
   ```

6. **Size cache appropriately**:
   - Small cache → High eviction rate
   - Large cache → Memory waste
   - Monitor: evictions/min, memory usage

7. **Invalidate stale content**:
   ```typescript
   // After update
   cache.invalidatePattern(/\/api\/users\/.*/);
   ```
